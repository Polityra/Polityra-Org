# Polityra

The official website for [Polityra](https://polityra.org), an independent
organization building open-source projects and making technology and
knowledge more accessible.

This repository contains the organization website, not the projects
themselves. It introduces Polityra, describes its principles, and showcases
independent initiatives including [Open Polityra](https://github.com/Polityra/Open-Polityra)
and Polityra CMS.

## Getting started

You need Node.js 20.9 or later and npm. From the repository directory:

```sh
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). If port 3000 is in use,
Next.js may choose another port; check the terminal output.

The website's content is maintained in the repository. No database or
environment variables are required for local development.

## Commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run lint` | Run ESLint |
| `npx tsc --noEmit` | Check TypeScript types |
| `npm run build` | Create a production build |
| `npm start` | Serve a completed production build |

## Project structure

- `src/app/` contains the Next.js App Router pages, shared layout, metadata
  routes, and loading and error states.
- `src/components/` contains shared navigation, footer, and project cards.
- `src/lib/projects.ts` contains the project catalog. Project detail pages
  and sitemap entries are generated from this data.
- `src/lib/seo.ts` contains the official site URL and shared page metadata.
- `public/` contains the site's images and icons.
- [Project brief](docs/project-brief.md) documents the site's purpose, content
  standards, and design requirements.

## Maintaining content

Add or update projects in `src/lib/projects.ts`. Include only verified
public links and distinguish intended capabilities from available features.
Project descriptions are used for their search and social metadata.

Each static page uses `pageMetadata` from `src/lib/seo.ts` to define its
title, description, and canonical path. The helper also creates its Open Graph
and X/Twitter metadata. If the social banner is replaced, update its dimensions
in the same file. The sitemap and `robots.txt` are generated by
`src/app/sitemap.ts` and `src/app/robots.ts`.

## Contributing

Contributions can include code, design, documentation, testing, and
accessibility improvements. Before opening a pull request, run the lint,
type-check, and build commands above, and describe the changes and how you
tested them.

For project-specific contributions, check the relevant project's own
repository and guidance. Please avoid publishing sensitive information in
issues or pull requests.
